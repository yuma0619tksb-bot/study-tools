# claude.ai プロジェクト用:資料の扱い(定型文)

各科目のプロジェクト指示の末尾に、下のブロックをそのまま貼る。
授業ごとの情報(担当・評価方法・回答形式など)は project-instructions-builder スキルで別に作る。

ナレッジには、元PDFではなく `python3 tools/materials.py bundle --subject <科目>` で作った
`exports/claude_project/<科目>/` の中身(`00_資料目次.md` と各資料の `.md`)をアップする。
元PDFは図を見たいものだけ追加する。

```
## 資料の扱い
- ナレッジの「00_資料目次.md」で、どの回・どの資料に載っているかを先に確認してから該当資料を読む。
- 各資料の .md は「要約(digest)→ ページごとの本文(## p.N)」の順で並んでいる。まず要約とキーワード索引で該当ページを決め、そのページを根拠にする。
- 回答で資料を使ったときは「(資料名 p.N)」の形で出典を書く。資料に無い内容を補うときは「資料外」と明記する。
- 「[OCR待ち]」「[判読不能]」のページは内容が欠けている。そのページが必要なときは、私に該当ページの画像を貼るよう頼む。
- 新しい資料を貼られたら、回答の最後に「資料目次に追加すべき一言要約(40字以内)」を1行で示す(私がリポジトリ側に反映する)。
```
